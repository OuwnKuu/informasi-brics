# Informasi BRICS: Berbagai Macam Informasi Mengenai BRICS yang Ringkas dan Sederhana

<br>
BRICS baru-baru ini dianggap sebagai organisasi yang anggota-anggotanya dianggap musuh oleh beberapa negara Barat. Aplikasi ini akan menyampaikan sejarah dan daftar negara anggotanya dengan cara yang intuitif.
<br>

## Bagaimana cara untuk mendapatkan aplikasi ini?

Aplikasi ini mudah didapatkan kok. Berikut cara mendapatkan dan menjalaninya di ponsel Android kalian:
1. Siapkan Android Studio di komputer.
2. Di halaman utama, tekan tombol Clone Repository.
3. Masukkan link berikut di bagian URL: ```https://github.com/OuwnKuu/informasi-brics```
4. Tekan tombol Clone.
5. Tunggu cloning selesai, setelah itu masuk ke project.
6. Colok kabel USB dari HP ke komputer, pastikan mode developer dan debugging via USB sudah aktif pada HP.
7. Setelah terdeteksi, lakukan run pada HP yang dicolok.
8. Proses build and install akan selesai dan HP kalian akan terinstal aplikasi ini.
